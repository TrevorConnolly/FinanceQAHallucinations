## Files written

- `tier_a_long.csv` — one row per (corpus × experiment), metric means.
- `tier_a_pooled_by_industry.csv` — Tier A means pooled by `genre` (finance vs FDA labels).
- `tier_a_delta_vs_baseline.csv` — Δ vs baseline per corpus.
- `tier_a_cross_corpus.csv` — mean/min/max of Δ across corpora per experiment.
- `tier_b_long.csv`, `tier_b_by_corpus.csv`, `tier_b_pooled_by_genre.csv` — Tier B only.

## Using these files for presentation graphics

- **CSV → charts:** Import any of the CSVs into **Excel, Google Sheets, or Numbers** and insert **bar / clustered bar / heatmap** charts. `tier_a_pooled_by_industry.csv` and `tier_a_cross_corpus.csv` are the quickest for slides.
- **Python:** `pandas.read_csv` + **matplotlib** or **plotly** for Δ vs baseline **forest plots** (one row per corpus per experiment).
- **This markdown:** Renders in GitHub, VS Code, or paste tables into **Slides/Keynote** as tables, or use as a script for figures.
- **Tier A vs B:** Use **separate figures** — do not put Tier A Δ-next-to-baseline on the same axis as Tier B raw means.
